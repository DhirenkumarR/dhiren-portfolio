# Dhirenkumar Rathod Portfolio

React + Vite static portfolio website with a static contact form.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
1. Create a GitHub repository, for example `dhiren-portfolio`.
2. Push this code.
3. In `package.json`, add this line at the top level:
```json
"homepage": "https://DhirenkumarR.github.io/dhiren-portfolio"
```
4. Run:
```bash
npm run deploy
```

For a user/organization page repository named `DhirenkumarR.github.io`, use:
```json
"homepage": "https://DhirenkumarR.github.io"
```
